# Morganick Job Master downloads

Current crew preview: **0.1.0-preview.57-full-portable**. Windows 11, Intel/AMD x64.

## Update your existing program

**[Download MJ Updater](https://github.com/DerekColeman75/morganick-job-master-downloads/releases/latest/download/MJ-Updater.exe)**

1. Download the file, then open **MJ-Updater.exe** from your Downloads folder.
2. It finds an installed copy of MJ where possible. If you use a portable copy, choose its `Morganick.JobDataViewer.exe` once.
3. Click **Update from online**. MJ downloads and verifies the latest release, backs up the current program and reopens it after updating. Save your job draft if prompted.

Once your program has the online updater, you can also use **Tools & help → Update program → Update from online**.

The download page cannot directly change files on your laptop. Windows needs you to open the updater. No GitHub account or separate .NET installation is required for the downloads.

## Set up a new laptop or use USB

**[Download the full portable program](https://github.com/DerekColeman75/morganick-job-master-downloads/releases/latest/download/MJ-Full-Portable.zip)**

Extract the whole ZIP into a local folder and open `Morganick.JobDataViewer.exe`. You can also bring the unchanged ZIP on USB and select it in **Update program → Choose newer release ZIP**.

## Your jobs stay on the laptop

Updates replace program files. Original recordings, saved job drafts, customer remarks, START/FINISH markers stored in those drafts and exported PDFs stay in place. Save unsaved work as a job draft before updating.

Job review and PDF tools still work offline. The application contacts the download service only when you ask for an online update. No job recording or report is uploaded by the updater.

## Report a problem

In v57 and later, click **Report a problem** at the bottom of MJ, or open the [support form](https://morganick-job-master.netlify.app/support/). No sign-in is needed. Enter your name, choose whether you can keep working and explain what happened, then click **Send report**. The form needs internet and keeps the open job in MJ. It does not attach your recording. Leave passwords and customer details out; contact dispatch for urgent help.

Online release notices are signed with Morganick's update key, and downloaded ZIPs must match the signed checksum. This is separate from Windows publisher signing: this crew preview is **not yet Authenticode-signed**. Follow your company's Windows security policy.

Only packaged downloads and these instructions are published here. Application source code and customer job files are not included. The full portable ZIP contains the application and runtime licence notices.
